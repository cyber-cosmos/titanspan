# Security Policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/titanspan/titanspan/security/advisories/new>

Do not report an unpatched vulnerability in a public issue or discussion.
Include the affected commit or version, impact, reproduction steps, and any
safe mitigation you identified. Maintainers will coordinate investigation and
public disclosure through a private advisory.

## Supported versions

No stable release has been published. Until one is available, security fixes
are considered for the latest `main` branch.

## Dependency security

Dependabot alerts and security updates, dependency auditing, secret scanning,
and CodeQL are configured where available for this public repository.
