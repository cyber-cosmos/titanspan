# Workflows

Stateful graph workflows are planned on top of LangGraph. Future work may add
typed state, nodes, reducers, checkpointing, interruptions, resumption,
authorization, streaming, and deterministic test helpers.

There is no Titanspan workflow builder or execution API today. Check the
[roadmap](https://github.com/titanspan/titanspan/blob/main/ROADMAP.md) for
planned milestones.
